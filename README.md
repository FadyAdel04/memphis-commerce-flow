Brand & Style

This design system combines the expressive energy of Modern Memphis and Neo-Brutalist graphic traditions with the rigorous utility of high-performance B2B SaaS workflows. Built specifically for an Egyptian social-commerce workspace platform, the aesthetic bridges regional retail vibrance with serious merchant tooling.

Brand Personality & Core Mood

Dynamic & Kinetic: Spirited, entrepreneurial, and unmistakably modern.

Pragmatic & Structured: Beneath the playful geometric accents lies a clean, hyper-functional SaaS engine engineered for high-throughput order management, social messaging, and inventory synchronization.

Culturally Grounded: Seamless bilingual harmony between Arabic and Latin scripts, celebrating local commercial dynamism without resorting to cliché ornament.

Visual Aesthetic

The style employs tactile neo-brutalism infused with 1980s Memphis group geometry: chunky 2px structural strokes, sharp hard-offset drop shadows (no feathering), warm cream foundational canvases, and vibrant pop-accent fills (violet, pink, yellow, mint). Tactile stickers, floating geometric motifs (four-point stars, dot grids, squiggles, pills), and tangible mechanical button presses create a lively, high-conversion landing environment.

Colors

The palette establishes an energetic visual rhythm against a warm, physical-paper baseline. High contrast between the deep slate borders/text and the warm cream background ensures readability and crisp structural definition.

Role Assignments

Base / Canvas: `#FFFDF5` (Warm Cream). Softens the starkness of pure digital white, evoking physical print stock and editorial warmth.

Foreground & Structure: `#1E293B` (Deep Slate). Replaces pure black for all structural 2px borders, typography, hard retro shadows, and dense iconography.

Primary Brand: `#8B5CF6` (Vibrant Violet). Anchors primary actions, core platform navigation, brand hero containers, and main conversion funnels.

Secondary Accent: `#F472B6` (Punchy Pink). Reserved for social-commerce tags, attention grabs, conversion highlights, notification pings, and playful stickers.

Tertiary Accent: `#FBBF24` (Energetic Yellow). Used for highlight backdrops, promotional badges, metric flags, and energetic graphic sparkles.

Quaternary Accent: `#34D399` (Fresh Mint). Signals order success, revenue growth graphs, active WhatsApp/social channel states, and affirmative indicators.

Subtle Layering: `#E2E8F0` (Muted Slate / Offset Layer). Used for dual-tone stepped shadows and background geometric grid lines.

Color Rules

Every colored container or badge must sit inside a solid 2px `#1E293B` stroke.

Avoid low-contrast color combinations: text on violet, pink, or mint surfaces must use `#1E293B` for punchy retro contrast or pure white `#FFFFFF` strictly when meeting AA WCAG thresholds. Text on yellow surfaces must strictly be `#1E293B`.

Typography

The typographic hierarchy is engineered to treat Arabic and English on equal footing. `ibmPlexSans` (paired natively with IBM Plex Sans Arabic) provides the structured, neo-grotesque authority demanded by prominent display titles, metric callouts, and punchy sticker badges. `inter` handles body text, complex SaaS microcopy, tabular data, and functional forms with maximum optical neutrality and legibility.

Bilingual Handling

In RTL contexts, line-height multipliers for headings and body increase by 10-15% to maintain visual balance across Arabic diacritics and descenders.

Numbers within SaaS dashboards and conversion stats default to bold, tabular Latin numerals or unified Eastern Arabic numerals based on merchant locale settings.

Layout & Spacing

The system runs on an 8pt base spatial unit with 4pt half-steps for micro-alignments, pill badges, and input paddings.

Grid Configuration

Desktop (1024px+): 12-column grid, max container width `1200px` (`75rem`), with `24px` (`1.5rem`) gutters and variable margins centering the canvas.

Tablet (768px - 1023px): 8-column grid with `20px` gutters and `24px` margins.

Mobile (320px - 767px): 4-column grid with `16px` (`1rem`) gutters and `16px` safe margins.

Composition & Reflow Rules

Memphis Feature Composition: Landing sections alternate between rigid SaaS preview cards and floating geometric accents. Decorative stars, squiggles, and dots are absolutely positioned relative to parent cards to prevent layout shifts.

Asymmetric Offsets: Feature groupings break strict symmetry using 12px-24px vertical offsets between adjacent column cards, emphasizing the neo-memphis editorial layout.

RTL Mirroring: Fluid layouts invert automatically along the horizontal axis, keeping interactive controls aligned to reading flow.

Elevation & Depth

Visual hierarchy does not rely on blurred ambient dropshadows or translucent glassmorphism. Depth is entirely tactile, graphic, and mechanical.

The Hard Offset Shadow System

Level 0 (Flat): 2px solid `#1E293B` outline with zero offset. Applied to baseline fields, inactive table rows, and secondary flat badges.

Level 1 (Default Interactive & Surface Elevation): Solid offset of `4px 4px 0px #1E293B`. Used for primary cards, feature blocks, text fields, and standard buttons.

Level 2 (High-Emphasis Hero Elevation): Stepped dual shadow: `4px 4px 0px #1E293B, 8px 8px 0px #E2E8F0`. Used for the main hero product showcase card, key pricing tiers, and primary floating tooltips.

Level 3 (Pressed / Active State): Zero offset shadow (`0px 0px 0px #1E293B`) coupled with a physical `translate(4px, 4px)` transform. The element mechanically drops into the page upon click/tap.

Border Rigor

All elevated components carry a consistent `2px solid #1E293B` frame. Color fills never bleed to borderless edges; the dark frame always acts as the structural containment vessel.

Shapes

The design uses a mixed-radius paradigm that merges brutalist geometry with friendly rounded curves. Sharp corners are avoided in favor of friendly, touch-friendly perimeters.

Radius System

Standard UI Cards & Containers: `16px` (`rounded-lg`). Provides a stable, modern silhouette for dashboard modules, metric cards, and dialog boxes.

Hero Containers & Large Surface Panels: `24px` (`rounded-xl`). Used for full-width testimonial banners and main dashboard preview wrappers.

Inputs, Checkboxes, & Micro-Cards: `8px` (standard base). Maintains compact precision within data-heavy forms and table rows.

Buttons, Sticker Badges, & Filter Chips: `9999px` (Full Pill). Injects playful retro energy, establishing a stark contrast against rectangular cards.

Memphis Geometric Accents

Pills: Miniature colored rounded ovals (rotated at -6°, 4°, or 12°).

Geometric Asterisks / 4-Point Stars: Sharp vector stars placed near conversion metrics and badge headers.

Dot Matrix: 4x4 or 6x6 arrays of 4px circles in `#1E293B` or `#E2E8F0` positioned adjacent to card corners.

Components

Buttons

Primary Button: Pill-shaped (`rounded-full`), background `#8B5CF6`, text `#FFFFFF`, 2px solid `#1E293B` border, and `4px 4px 0px #1E293B` hard shadow. Padding: `12px 28px`. Hover: `translate(-2px, -2px)` with shadow expanding to `6px 6px 0px #1E293B`. Active: `translate(4px, 4px)` with shadow collapsing to `0px 0px 0px`.

Secondary Button: Pill-shaped, background `#FFFDF5`, text `#1E293B`, 2px solid `#1E293B`, and `4px 4px 0px #1E293B` shadow. Hover fill transitions to `#FBBF24`.

Destructive / Accent Button: Pill-shaped, background `#F472B6`, text `#1E293B`, 2px solid `#1E293B`.

Sticker Badges & Chips

Stickers: Pill or 8px rounded tags tilted slightly (`-2deg` to `3deg`), featuring high-weight uppercase/bold text (`badge-sticker`), 2px `#1E293B` border, and a compact `2px 2px 0px #1E293B` drop shadow. Backdrops use pink, yellow, or mint.

Filter Chips: Pill shape, background `#FFFDF5`, 2px solid `#1E293B`. When active: background switches to `#8B5CF6`, text turns white, and a `3px 3px 0px #1E293B` shadow is applied.

Input Fields

Container: 8px radius, 2px solid `#1E293B`, background `#FFFFFF`, padding `12px 16px`. Body font `inter`, `16px`.

Default State: Flat or `2px 2px 0px #1E293B`.

Focus State: `4px 4px 0px #1E293B` shadow, border remains `#1E293B`, outline none. Optional subtle tertiary accent highlight tag on the floating label.

Cards & Feature Containers

Standard Card: 16px radius, background `#FFFFFF` or `#FFFDF5`, 2px solid `#1E293B`, `4px 4px 0px #1E293B` shadow. Contains generous internal padding (`24px` to `32px`).

Hero / Interactive Card: 24px radius, multi-layer hard offset (`4px 4px 0px #1E293B, 8px 8px 0px #E2E8F0`).

Header Section of Card: Often paired with a contrasting background strip (e.g., `#FBBF24` or `#34D399`) separated by a horizontal 2px solid `#1E293B` divider line.

Checkboxes & Radios

Checkbox: Square with 4px radius, 2px solid `#1E293B`, background `#FFFFFF`, size `20px x 20px`. Checked state: background `#34D399` with a bold black checkmark vector, accompanied by a `2px 2px 0px #1E293B` shadow.

Radio: Circular, 2px solid `#1E293B`. Checked state: `#8B5CF6` inner solid dot with a 4px white buffer.

SaaS Realistic UI Modules

Social-Commerce Live Feed: Card displaying incoming multi-channel orders (WhatsApp, Instagram, TikTok) with platform-specific pill tags, bold price figures, and status pills (`#34D399` for paid, `#FBBF24` for pending dispatch).

Metric Tiles: Compact 12px rounded boxes with mini dot-grid watermarks, prominent `headline-lg` metrics in `#1E293B`, and micro growth badges with `+28%` encased in pink or mint pill stickers.

## Supabase Setup

This project uses Supabase for authentication, database, and row-level security (RLS) to implement multi-tenancy.

### Environment Variables

Create a `.env` file in the root directory with:

```env
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_PUBLISHABLE_KEY=your_supabase_anon_key
```

### Database Schema and RLS

To set up the database with proper multi-tenancy isolation:

1. Go to your Supabase project dashboard → SQL Editor
2. Copy and run the SQL from `supabase/migrations/20240904000001_initial_schema.sql`
3. This will create:
   - Stores table linked to auth.users
   - Products, orders, conversations, customers, staff tables
   - Row Level Security (RLS) policies on all tables
   - Triggers for automatic updated_at timestamps
   - Indexes for performance

### Multi-Tenant Architecture

The implementation ensures complete store isolation:
- Each store can only access its own data
- RLS policies enforce `user_id = auth.uid()` on all queries
- Even if API keys are compromised, attackers can only access stores they own
- All tables are scoped to individual stores via store_id foreign keys

### Authentication Flow

1. User signs up with name, email, password
2. After email verification, user completes store onboarding:
   - Store name
   - Category (fashion, beauty, electronics, food, accessories, other)
   - Sales platforms (Instagram, WhatsApp, Facebook, Website - checkboxes)
   - Number of products
3. User is redirected to their personal store dashboard
4. Dashboard shows store information and navigation to:
   - Orders management
   - Products inventory
   - Customers
   - Communication channels (WhatsApp/Instagram/Facebook)
   - Analytics
   - Settings
